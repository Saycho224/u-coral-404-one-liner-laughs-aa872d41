# One-Liner Laughs

One original joke line, for make.fun's
[One-Liner Laughs](https://make.fun/bounty/u-coral-404-one-liner-laughs-aa872d41) bounty.

> I clicked 'I'm not a robot' and the checkbox hesitated — even the test isn't sure about me anymore.

`main.py` writes `entry.txt` to `$MAKEFUN_OUTPUT_DIR` (default `/output`)
and verifies the written bytes byte-for-byte.
